# 车牌识别模型轴对齐裁切重训（2026-10-10）

识别模型 `plate_rec_cn_96x32` 按运行时裁切方式重训，检测模型不变。评测脚本、评测集、投票模拟与 `../plate_e2e_20261009/` 相同，「前」列即该目录的结果。

## 训练

与原配方相同的部分：PlateRecNet、96×32 输入、66 类字符集、60 epoch、batch 256、AdamW lr 1e-3 余弦退火、seed 0、8 个 DataLoader worker、`augment()` 中全部增强（仿射 ±5°、透视、亮度对比度、运动模糊、JPEG 30–90、高斯噪声）、val = CCPD2020 green val（1001）、按 val 整牌准确率选 best。

改动：

1. 裁切：`--crop-mode axisctx`。`training/gen_platerec_axis_crops.py` 用检测 ONNX（`plate_e2e_eval.py` 的 letterbox / 解码 / NMS，GPU 上经 onnx2torch 运行，与 onnxruntime CPU 的框差 ≈0.03 px）在每张训练图上取与 CCPD 标注框 IoU 最大的检测框（< 0.5 时用标注轴对齐框：train 1379 / 355301，val 1 / 1001），把框周围 ±0.4 倍宽高的区域无损存为 PNG。训练时在该区域上按运行时 stage2 方式（框四边各扩 0.08、半像素双线性、坐标先夹紧）采样到 96×32，与 `plate_e2e_eval.crop_rec` 逐像素对照最大差 0.011。
2. 框抖动：概率 0.8，中心偏移 U(±0.05)×框宽/高，宽、高各乘 exp(U(±0.12))。幅度参照检测框相对标注框的偏差（1000 张抽样：纵向中心偏移标准差 0.046，log 高度比标准差 0.135）。
3. 数据：train = CCPD2019 除 np 外全部子集 + CCPD2020 green train，**去掉评测集中的 2400 张 CCPD2019 图**（每个子集 300），共 355 301 张（原 357 701）。CCPD2020 green test 不参与训练。

命令（GPU x86 工作站，工作目录为训练工作区）：

```bash
.venv/bin/python training/gen_platerec_axis_crops.py --det models/plate_det_yolox_tiny_640.onnx \
  --exclude-set evaluation/data/plate_e2e/eval_set.jsonl --out data/processed/platerec_axisctx --workers 12
.venv/bin/python training/train_platerec.py --crop-mode axisctx --axisctx-dir data/processed/platerec_axisctx \
  --epochs 60 --batch-size 256 --num-workers 8 --out training/outputs/platerec_cn_axis
.venv/bin/python training/export_platerec.py --ckpt training/outputs/platerec_cn_axis/best.pth --out plate_rec_cn_96x32.onnx
```

裁切库 `rows.jsonl` sha256 `8e25661f…9fa7`。每 epoch 约 555 s（GB10 与其他任务共用），val 整牌准确率最高 84.3%（epoch 55）。

新模型训练时没见过评测集里的 2400 张 CCPD2019 图，旧模型见过；green test 对两者都是留出集。
